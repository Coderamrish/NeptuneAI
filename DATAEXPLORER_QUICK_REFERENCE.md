## 🚀 How to Use

### Step 1: View Data
1. Open Data Explorer page
2. See statistics cards at top
3. Scroll down to view table

### Step 2: Filter Data
1. Click "Toggle Filters" (or show by default)
2. Adjust any filters
3. Results update instantly

### Step 3: Explore Views
1. **Table Tab**: Click rows for details
2. **Charts Tab**: Hover over visualizations
3. **Map Tab**: Click/hover on markers

### Step 4: Export Results
1. Use header buttons to export all data
2. Choose: CSV, JSON, or Excel
3. Or export individual stations from dialog

### Step 5: Share Insights
1. Share exported files
2. Share filtered views
3. Take screenshots of charts

## 📊 Statistics Explained

### Temperature Trend
- **↑ Arrow**: Temperature increasing
- **↓ Arrow**: Temperature decreasing
- **Value**: Change in degrees

### Salinity Trend
- **↑ Arrow**: Salinity increasing
- **↓ Arrow**: Salinity decreasing
- **Value**: Change in PSU

### Quality Percentage
- **0-30%**: Low quality data
- **30-60%**: Medium quality
- **60-90%**: Good quality
- **90-100%**: Excellent quality

### Depth Metrics
- **0-500m**: Shallow water
- **500-2000m**: Mid-depth
- **2000-5000m**: Deep water
- **5000m+**: Very deep

## 📈 Interpreting Charts

### Histograms
- **Peak**: Most common value
- **Spread**: Range of variation
- **Shape**: Distribution pattern

### Scatter Plot
- **Clusters**: Grouped data
- **Outliers**: Unusual values
- **Color Gradient**: Depth variation

### Pie Chart
- **Slices**: Categories
- **Size**: Relative proportion
- **Hover**: Exact counts

### Bar Chart
- **Height**: Value magnitude
- **Width**: Category width
- **Hover**: Exact numbers

### Map
- **Marker Color**: Temperature value
- **Marker Size**: Visibility (fixed)
- **Clustering**: Geographic patterns

## 🆘 Troubleshooting

### Data Not Loading
1. Check internet connection
2. Wait for page load
3. Refresh page
4. Clear browser cache

### Filters Not Working
1. Clear all filters
2. Reapply one at a time
3. Refresh page
4. Check data range

### Export Issues
1. Check browser permissions
2. Try different format
3. Check file size
4. Clear browser cache

### Map Not Showing
1. Check map permissions
2. Scroll down to map tab
3. Wait for rendering
4. Refresh page
